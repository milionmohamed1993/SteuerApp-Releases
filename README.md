# Steuerklar – Downloads

Installer der Steuerklar-Desktop-App: Steuererklärung vorbereiten mit einer KI, die auf deinem Computer läuft.

**Download-Seite:** https://milionmohamed1993.github.io/SteuerApp-Releases/

- Alle Versionen findest du unter [Releases](https://github.com/milionmohamed1993/SteuerApp-Releases/releases).
- Beim ersten Start richtet die App die passende KI automatisch ein (einmaliger Download, danach ohne Internet).
- Deine Daten bleiben auf deinem Gerät.

Dieses Repository enthält nur die veröffentlichten Installer und die Download-Seite, keinen Quellcode.
